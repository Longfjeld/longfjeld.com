# Leveranse

## Aktiv nettside

- `index.html` – felles introduksjon og innganger til prosjektene
- `style.css` – hele det felles Minimal Glass-designet
- `oppskrifter/index.html` – presentasjon av Oppskrifter
- `akkordia/index.html` – presentasjon av Akkordia
- `tekstilig/index.html` – presentasjon av Tekstilig
- `404.html` – enkel feilside
- `CNAME` – custom domain for branch-basert GitHub Pages
- `.nojekyll` – sørger for helt statisk publisering uten Jekyll-behandling

## Bevisste valg

- Hype-runtime og Hype-prosjektfiler er ikke med i aktiv leveranse.
- Ingen JavaScript er nødvendig for navigasjon eller layout.
- Ingen privat data- eller synkfunksjonalitet inngår i nettstedet.
- OneDrive/iCloud omtales kun som en del av prosjektpresentasjonene.
